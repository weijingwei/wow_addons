# wjw_工具箱（魔兽世界插件）

魔兽世界正式服小插件，把「任务寻路」「自动卖垃圾」「专业技能升级规划」三个功能合并成一个插件目录 `wjw_Toolkit`，只需安装一份。

## 功能

**任务寻路（`/wjw qp`）**：选中或追踪任务后，自动在小地图、屏幕和世界地图上画出从玩家到任务目的地的连线；游戏没有提供任务点的任务不会乱画。

**自动卖垃圾（`/wjw sell`）**：打开商人界面时，自动把背包里所有灰色（品质 0）物品卖给商人，结束后在聊天框提示卖出的件数与获得的金币；支持「永不卖出名单」，名单里的物品（即使品质为 0）永远不会被卖出。

**专业技能升级规划（`/wjw craft`）**：读取当前专业等级与已经学会的配方，按材料件数规划升级路径，逐段给出建议制作的配方、所需材料与背包里的缺口；现有配方不再涨点时提示断点，并可用训练师坐标指路。规划不使用金币价格。

## 安装

1. 把 `wjw_Toolkit` 整个文件夹复制到游戏的 `Interface\AddOns\` 目录下；
2. 重启客户端，或退回到角色选择界面后重新进入游戏。

## 兼容

- 国服正式服（客户端目录 `_forever_`）
- 插件清单 `## Interface: 16001`

## 命令速查

| 命令 | 说明 |
|---|---|
| `/wjw` | 总入口，列出全部命令与设置页位置；也可直接用 `/wjw qp`、`/wjw sell` |
| `/wjw qp` | 查看当前目标与距离 |
| `/wjw qp quest` | 用当前选中/追踪的任务设定目标 |
| `/wjw qp clear` | 清除目标 |
| `/wjw qp auto on\|off` | 自动跟随追踪/选中任务（默认开启） |
| `/wjw qp arrow on\|off` | 屏幕箭头开关 |
| `/wjw sell` | 开 / 关自动卖出（不带参数直接切换） |
| `/wjw sell add` | 把鼠标指向的物品加入永不卖出名单 |
| `/wjw sell remove` | 从永不卖出名单移除物品（可带 itemID 或名字片段） |
| `/wjw sell list` | 查看永不卖出名单 |
| `/wjw sell clear` | 清空永不卖出名单 |
| `/wjw craft` | 规划当前打开（或上次使用）的专业，到现有配方断点为止 |
| `/wjw craft <目标等级>` | 规划到指定等级 |
| `/wjw craft <专业名> [目标等级]` | 指定专业（和目标）后规划 |
| `/wjw craft skip <材料名>` | 把材料加入跳过名单（规划时排除） |
| `/wjw craft skiprecipe <配方名>` | 把配方加入跳过名单 |
| `/wjw craft unskip <名称>` | 从两个跳过名单中移除 |
| `/wjw craft list` | 查看两个跳过名单 |
| `/wjw craft reset` | 清空跳过名单与目标等级 |
| `/wjw craft trainer [类型] [all]` | 查询训练师位置（无参时只显示当前地图上当前专业距离最近的一个；指定类型时列出当前地图该类型全部并按距离排序；`all` 列出全部地图。当前地图查不到时给出同大陆直线距离最近的一个） |
| `/wjw craft help` | 显示专业技能帮助 |

## 设置页

游戏「选项 → 插件」里有三个分类：

- `wjw_工具箱 · 任务寻路`
- `wjw_工具箱 · 自动卖垃圾`
- `wjw_工具箱 · 专业技能`

也可以用 `/wjw sell config` 直接打开自动卖垃圾的设置面板。

## 数据与估算说明

- **训练师坐标**来自开源项目 QuestieDB（数据内置在插件里，不联网）。数据可能不全：珠宝加工、铭文、考古学在原数据中没有对应训练师。
- 地图上的训练师标记按以下顺序判定类型：显式指定过的类型（`/wjw craft trainer <类型>` 或规划过的专业）→ 专业窗口可见时的专业 → 上次规划的专业；都取不到时不显示标记（不再猜测）。
- **涨点概率与难度分界是社区经验估算，不是官方数据**：橙色 100%、黄色 60%、绿色 25%；配方有效区间的前 25% 按橙色、25%–65% 按黄色、余下按绿色处理。
- 只规划**已经学会**的配方；规划到现有配方的断点为止，之后再升级需要自行找训练师学习新配方（可用 `/wjw craft trainer` 查位置）。
- 材料按**件数**估算最省路线，**不使用金币价格**；材料缺口按背包现有数量计算。
- 「配方列表行内高亮」是**实验性**功能，依赖暴雪专业界面的内部结构，游戏大版本更新后可能失效；可在设置页关闭。

## 目录结构

| 文件 | 职责 |
|---|---|
| `wjw_Toolkit.toc` | 插件清单：Interface 号、SavedVariables、加载顺序 |
| `PathCore.lua` | 寻路核心：斜杠命令、目标状态、任务点解析、自动追踪、存档 |
| `PathMap.lua` | 坐标换算：地图坐标 ↔ 世界坐标、距离、方位角 |
| `PathOverlay.lua` | 绘制：小地图虚线、世界地图虚线、屏幕箭头 |
| `PathMain.lua` | 事件注册、节流刷新、自动追踪轮询 |
| `SellCore.lua` | 自动卖垃圾核心：背包扫描、出售会话、黑名单、`/wjw sell` 命令 |
| `SellOptions.lua` | 自动卖垃圾设置面板 |
| `Options.lua` | 任务寻路设置面板 |

本目录下的 `legacy/QuestPath/`、`legacy/WuXianAutoSell/` 是合并前的两个独立插件源码备份（不随插件发布，仅用于回退参考），安装时只用 `wjw_Toolkit/`。
