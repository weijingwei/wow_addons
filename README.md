# wjw_工具箱（魔兽世界插件）

魔兽世界正式服小插件，把「任务寻路」和「自动卖垃圾」两个功能合并成一个插件目录 `wjw_Toolkit`，只需安装一份。

## 功能

**任务寻路（`/qp`）**：选中或追踪任务后，自动在小地图、屏幕和世界地图上画出从玩家到任务目的地的连线；游戏没有提供任务点的任务不会乱画。

**自动卖垃圾（`/xsell`）**：打开商人界面时，自动把背包里所有灰色（品质 0）物品卖给商人，结束后在聊天框提示卖出的件数与获得的金币；支持「永不卖出名单」，名单里的物品（即使品质为 0）永远不会被卖出。

## 安装

1. 把 `wjw_Toolkit` 整个文件夹复制到游戏的 `Interface\AddOns\` 目录下；
2. 重启客户端，或退回到角色选择界面后重新进入游戏。

## 兼容

- 国服正式服（客户端目录 `_forever_`）
- 插件清单 `## Interface: 16001`

## 命令速查

| 命令 | 说明 |
|---|---|
| `/wjw` | 查看两个功能的全部命令（总帮助） |
| `/qp` | 查看当前目标与距离 |
| `/qp quest` | 用当前选中/追踪的任务设定目标 |
| `/qp clear` | 清除目标 |
| `/qp auto on\|off` | 自动跟随追踪/选中任务（默认开启） |
| `/qp arrow on\|off` | 屏幕箭头开关 |
| `/xsell` | 开 / 关自动卖出（不带参数直接切换） |
| `/xsell add` | 把鼠标指向的物品加入永不卖出名单 |
| `/xsell remove` | 从永不卖出名单移除物品（可带 itemID 或名字片段） |
| `/xsell list` | 查看永不卖出名单 |
| `/xsell clear` | 清空永不卖出名单 |

## 设置页

游戏「选项 → 插件」里有两个分类：

- `wjw_工具箱 · 任务寻路`
- `wjw_工具箱 · 自动卖垃圾`

也可以用 `/xsell config` 直接打开自动卖垃圾的设置面板。

## 目录结构

| 文件 | 职责 |
|---|---|
| `wjw_Toolkit.toc` | 插件清单：Interface 号、SavedVariables、加载顺序 |
| `PathCore.lua` | 寻路核心：斜杠命令、目标状态、任务点解析、自动追踪、存档 |
| `PathMap.lua` | 坐标换算：地图坐标 ↔ 世界坐标、距离、方位角 |
| `PathOverlay.lua` | 绘制：小地图虚线、世界地图虚线、屏幕箭头 |
| `PathMain.lua` | 事件注册、节流刷新、自动追踪轮询 |
| `SellCore.lua` | 自动卖垃圾核心：背包扫描、出售会话、黑名单、`/xsell` 命令 |
| `SellOptions.lua` | 自动卖垃圾设置面板 |
| `Options.lua` | 任务寻路设置面板 |

本目录下的 `legacy/QuestPath/`、`legacy/WuXianAutoSell/` 是合并前的两个独立插件源码备份（不随插件发布，仅用于回退参考），安装时只用 `wjw_Toolkit/`。
